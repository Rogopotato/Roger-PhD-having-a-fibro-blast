# Roger-PhD-having-a-fibro-blast
R and Slurm scripts used in Roger's PhD. Scripts for bulk RNA sequencing, bulk ATAC sequencing, gene alignment and statistical analysis.
These are linked to my (Roger's) PhD project. These scripts are free to use by anyone.
Original author's and other contributions will be acknowledged where relevant.

Slurm scripts will be for bulk RNA and bulk ATAC sequencing gene alignment and pre-processing workflows.
R scripts will be for differential expression and chromatin accessiblity analysis as well as for some statistical analyses used during this PhD.
